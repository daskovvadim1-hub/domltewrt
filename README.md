# ДОМ LTE WRT

Кастомная сборка OpenWrt для x86-64 ПК с Legacy BIOS и ext4.

## Цель первого этапа
- Собирать образ в GitHub Actions, без установки Linux/WSL на Windows.
- Использовать официальный OpenWrt 25.12.6 ImageBuilder для **x86/legacy** (не EFI).
- Получить образ для тестовой загрузки с USB. Внутренний диск компьютера не трогать.
- Добавить русский LuCI и базовые инструменты диагностики USB/LTE.

## План
1. Собрать воспроизводимый базовый образ и проверить загрузку/сеть.
2. Подключить Fibocom L850-GL через VERTELL VT-STATION-M.2 и определить фактический USB-режим модема.
3. После загрузки базового образа установить XMM/LTE-стек скриптом `scripts/install-fibocom-l850.sh`: `luci-proto-xmm`, `xmm-modem`, панели 4IceG и русский перевод. Скрипт рассчитан на OpenWrt 25.x (apk), по умолчанию использует APN `TT`, не меняет NVM модема и не перезагружает роутер.
4. Отдельным этапом проверить TTL/IPv6 Hop Limit и компоненты PassWall 2, Xray, sing-box, VLESS Reality/TLS.

## Важные ограничения
Поддержка конкретных функций L850-GL зависит от USB-композиции, драйверов и прошивки модема. CA и band locking зависят также от модема и сети оператора. PassWall 2 и часть LTE-панелей могут требовать сторонних feed'ов; они не считаются проверенными, пока не пройдут сборку и тест.

## Параметры
- Проект: ДОМ LTE WRT
- OpenWrt: 25.12.6
- Target: x86 / legacy
- Архитектура: x86-64
- Файловая система: ext4
- BIOS: Legacy BIOS (не EFI)
- APN: TT (проверить у оператора; в базовый образ автоматически не прошивается)

## Сборка
Workflow: **Build DОМ LTE WRT** в разделе GitHub Actions. Результат будет опубликован как workflow artifact после успешной сборки.


## Установка поддержки Fibocom L850-GL после первой загрузки

Сначала подключи роутер к интернету через любой доступный WAN. Затем передай файл `scripts/install-fibocom-l850.sh` на роутер и запусти от root. Скрипт устанавливает XMM-протокол из feed 132lan и LTE-панели из APK feed 4IceG. Значения по умолчанию: APN `TT`, русский перевод включён, автоматическая перезагрузка выключена. Перевод модема MBIM→NCM (запись NVM) не выполняется автоматически. Подробная инструкция: [docs/FIBOCOM-INSTALL.md](docs/FIBOCOM-INSTALL.md).
