# ДОМ LTE WRT

Кастомная сборка OpenWrt для x86-64 ПК с Legacy BIOS и ext4.

## Цель сборки

- Собирать единый образ в GitHub Actions, без установки Linux/WSL на Windows.
- Использовать официальный OpenWrt 25.12.6 ImageBuilder для **x86/legacy**.
- Получить образ для тестовой загрузки с USB. Внутренний диск компьютера не трогать.
- Включить в сам образ русский LuCI, XMM-протокол, USB NCM-драйверы, ModemData, ModemBand, SMS Tool и русские переводы.
- Проверять итоговый манифест: сборка не должна публиковать артефакт, если обязательные XMM/LTE-пакеты отсутствуют.

## Модемы и USB-режим

Целевые модемы: Fibocom L850-GL и L860-GL. Рабочая схема проекта — USB NCM + `proto xmm`.

**Важно:** сборка не переключает USB-композицию модема, не выполняет AT-команды записи в NVM и не меняет настройки модема. QMI/MBIM не используются в качестве сетевого протокола этого проекта.

## Состав образа

Пакеты задаются в `config/packages.txt`. Внешние подписанные репозитории 132lan и 4IceG подключаются на этапе ImageBuilder; их ключи проверяются до разрешения зависимостей. В итоговый образ должны попасть:

- `luci-proto-xmm`
- `luci-app-modemdata` и `modemdata`
- `luci-app-modemband`
- `luci-app-sms-tool-js`
- русские переводы ModemData, ModemBand и SMS Tool
- USB CDC-NCM и USB serial драйверы

Если пакет не разрешается или отсутствует в итоговом манифесте, workflow должен завершиться ошибкой, а не выдавать неполный образ за готовый.

## Параметры

- Проект: ДОМ LTE WRT
- OpenWrt: 25.12.6
- Target: x86 / legacy
- Архитектура: x86-64
- Файловая система: ext4
- Загрузка: Legacy BIOS
- APN: не прошивается автоматически; задаётся после проверки SIM и оператора

## Сборка и проверка

Workflow: **Build DOM LTE WRT** в разделе GitHub Actions. После успешной сборки артефакт публикуется как `dom-lte-wrt-x86-legacy-ext4`.

Успешный CI подтверждает разрешение пакетов и их присутствие в манифесте, но не заменяет проверку загрузки на конкретном ПК и тест модема с SIM-картой. После загрузки проверь LuCI → Network → Interfaces, наличие интерфейса XMM и страницы ModemData / ModemBand / SMS Tool.

## Ограничения

Фактическая работа модемных функций зависит от USB-идентификаторов, прошивки модема, AT-портов и сети оператора. Наличие панели не гарантирует поддержку каждой функции, включая CA, band locking или SMS. Не публикуй IMEI, IMSI, ICCID, номер SIM или пароли.

PassWall 2, Xray, sing-box, TTL и IPv6 Hop Limit — отдельный следующий этап после подтверждения стабильного LTE-соединения.
