# Матрица совместимости — ДОМ LTE WRT

Проверка источников: 2026-11-07. Фактическая совместимость проверяется на конкретной плате, модеме и версии прошивки.

## База x86
- OpenWrt 25.12.6 / target `x86/legacy` — для старого ПК с Legacy BIOS.
- Файловая система образа: ext4 combined.
- Русский LuCI: пакет `luci-i18n-base-ru`.
- Успешная GitHub Actions сборка проекта пока не подтверждена.

## Fibocom L850-GL / Intel XMM7360
- Подтверждение пользователя: на ранее использовавшейся OpenWrt-системе модем определялся как XMM, и интернет через него работал. Это сильный признак, что рабочий путь уже существовал, но его точная реализация пока неизвестна.
- В проекте `xmm7360-pci` есть отдельный Linux-драйвер для PCI ID `8086:7360`; README описывает получение интерфейса `wwan0` и запуск data channel через Python. Это не стандартные QMI/MBIM-драйверы OpenWrt и не готовый пакет ImageBuilder.
- Не добавлять `xmm7360-pci` вслепую в базовый образ: внешний модуль ядра должен быть собран строго под точную версию ядра OpenWrt. Несовпадение ABI приведёт к невозможности загрузить модуль.
- VERTELL VT-STATION-M.2 может определять, используется ли PCIe или USB-путь; это нужно подтвердить по конфигурации платы и системным данным.
- **Статус:** пользователь подтвердил рабочий интернет в прежней системе; точный драйвер, интерфейс и способ автозапуска ещё не установлены.

## LTE-панель и управление модемом
- Кандидат: `fildunsky/luci-app-5gmodem`. В README перечислен Fibocom L850 (Intel XMM) среди протестированных устройств.
- Заявлены мониторинг сигнала/оператора/CA, управление диапазонами, TTL/IPv6 Hop Limit, SMS, USSD и AT-консоль. Реальный набор функций зависит от доступных AT-портов и прошивки модема.
- Для OpenWrt 25.12 проект публикует APK. Workflow проекта будет прикладывать APK к артефактам отдельно; это не означает, что приложение уже встроено в rootfs. Его зависимости устанавливаются через APK после загрузки OpenWrt.
- Источник: https://github.com/fildunsky/luci-app-5gmodem

## QMI / MBIM / USB
- Типовые QMI/MBIM/USB-serial пакеты оставлены как диагностический запас, но они не являются драйвером PCIe XMM7360.
- Выбирать окончательный набор можно после проверки `lsusb`, `lspci -nn`, `dmesg`, `ip link` и устройств `/dev/tty*`.

## VPN
- PassWall 2, Xray и sing-box пока не включены в базовый образ: необходимо проверить APK/feed и зависимости именно для OpenWrt 25.12.6 и x86/legacy.
- VLESS Reality/TLS настраивается в соответствующем ядре Xray/sing-box, а не драйвером модема.

## Следующий шаг для точного переноса прежней рабочей схемы
Нужны данные с той OpenWrt-системы, где интернет через L850-GL уже работал. Если она ещё доступна, выполни:
```sh
uname -r
lspci -nn
lsusb
ip link
dmesg | grep -iE 'xmm|7360|wwan|fibocom'
ls -l /dev/ttyXMM* /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
```
Скрыть IMEI, IMSI, ICCID, номер SIM и пароли. Если прежней системы уже нет, скажи — подберём диагностический путь на текущем x86.
