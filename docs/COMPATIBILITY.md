# Матрица совместимости — ДОМ LTE WRT

Проверка источников: 2026-11-07. Это предварительная оценка по документации и опубликованным пакетам; фактическая совместимость проверяется на конкретном ПК и модеме.

## База x86
- **OpenWrt 25.12.6 / x86/legacy / ext4 combined** — официальный образ и ImageBuilder опубликованы.
- ImageBuilder: `openwrt-imagebuilder-25.12.6-x86-legacy.Linux-x86_64.tar.zst`
- SHA256: `5aa4348e026bd729dc54ca7f4f3f46ab7ed0d38a52beafd02d27cebca34ed2ef`
- Русский пакет LuCI `luci-i18n-base-ru` опубликован в ветке пакетов 25.12.
- **Статус:** формат сборки подтверждён по каталогу релиза; успешная GitHub Actions сборка проекта пока не подтверждена.

## Fibocom L850-GL / Intel XMM7360
- Репозиторий `fildunsky/luci-app-5gmodem` указывает Fibocom L850 в списке протестированных модемов.
- Приложение заявляет графику сигнала/оператора/технологии, CA-индикацию, выбор диапазонов, TTL/IPv6 Hop Limit, SMS, USSD и AT-консоль.
- Это подтверждает поддержку на уровне приложения для некоторых конфигураций L850, но не доказывает, что конкретный модем в VERTELL VT-STATION-M.2 будет доступен системе как USB-модем.
- Для XMM7360 важен режим подключения: PCIe и USB — разные пути. Не считать QMI/MBIM/serial драйверы автоматически подходящими, пока не увидим USB ID и интерфейсы устройства.
- **Статус:** перспективно, аппаратная проверка обязательна. Нужны `lsusb`, `dmesg`, `ip link` и список `/dev/ttyUSB*`/`/dev/ttyACM*` после подключения.

## LTE-панель
- Кандидат: `fildunsky/luci-app-5gmodem`; проект публикует APK для OpenWrt 25.12.x и IPK для 24.10.x.
- **Статус:** функционально подходит по заявленным возможностям и содержит L850 в tested list; в ImageBuilder пока не включена. Перед добавлением проверить конкретный APK, архитектуру x86_64 и зависимости.

## VPN
- PassWall 2, Xray и sing-box не включены в официальный минимальный пакетный набор ImageBuilder этой сборки.
- Для OpenWrt 25.12 требуется APK-совместимая сборка и совпадающие feeds/архитектура. Сторонние инструкции сами по себе не являются подтверждением совместимости.
- **Статус:** отложено до отдельной проверки источников пакетов и зависимостей. VLESS Reality/TLS — функции соответствующего ядра/конфигурации, а не отдельный драйвер OpenWrt.

## TTL / IPv6 Hop Limit
- `luci-app-5gmodem` заявляет настройку TTL и IPv6 Hop Limit через nftables/fw4.
- **Статус:** кандидат найден; проверить после определения интерфейса модема и теста правил fw4.

## Следующий аппаратный тест
На работающей OpenWrt системе подключить L850-GL и собрать вывод:
```sh
lsusb
dmesg | tail -n 100
ip link
ls -l /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
```
Не отправлять IMEI, IMSI, номер SIM или другие идентификаторы абонента. При необходимости их следует скрыть.
