# Проверка Fibocom L850-GL / L860-GL после первой загрузки

XMM-протокол и панели ModemData, ModemBand и SMS Tool должны быть установлены **внутри образа**. Отдельный установщик `scripts/install-fibocom-l850.sh` для штатной установки больше не требуется.

## Сохранённые ограничения

- Ожидаемая композиция модема: USB NCM + AT-порты.
- Сетевой протокол: `proto xmm`.
- Не переключать USB-режим модема.
- Не выполнять `AT+GTUSBMODE`, `at@nvm` или команды записи NVM.
- Не запускать установщик с `DO_MODE_SWITCH=1`.
- APN автоматически не задаётся: сначала уточнить APN у оператора.

## Проверка после загрузки

В LuCI проверь:

1. **Network → Interfaces** — должен присутствовать интерфейс XMM/LTE, если конфигурация создана для установленного модема.
2. **ModemData** — должна открываться страница данных модема.
3. **ModemBand** — должна открываться страница диапазонов.
4. **SMS Tool** — должна открываться панель SMS/USSD.

Если панели отсутствуют, не устанавливай пакеты наугад. Сначала проверь манифест именно установленного образа и вывод:

```sh
opkg list-installed 2>/dev/null | grep -Ei 'xmm|modemdata|modemband|sms-tool'
apk info 2>/dev/null | grep -Ei 'xmm|modemdata|modemband|sms-tool'
```

Для диагностики USB/AT-портов:

```sh
ls -l /dev/ttyACM* 2>/dev/null
lsusb
logread | grep -Ei 'xmm|cdc_ncm|ttyACM|fibocom'
```

Не публикуй IMEI, IMSI, ICCID, номер SIM или пароли.

## Что считается успешной проверкой

- Устройство загружается с USB в Legacy BIOS.
- LuCI открывается.
- Все обязательные пакеты присутствуют в манифесте.
- Модем определяется в ожидаемой NCM-композиции.
- XMM-интерфейс поднимается и передаёт трафик.
- Панели читают данные с корректного AT-порта.

Успешная сборка GitHub Actions подтверждает только сборку и наличие пакетов в манифесте. Работу модема и панелей нужно подтвердить на самом оборудовании.
